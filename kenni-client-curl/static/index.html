Kenni curl example

This page is served by ./serve.sh on http://localhost:8000. Its only role is to host the redirect-URI landing page at /callback so the browser has somewhere to land after sign-in (and after RP-initiated sign-out).

The flow itself runs in your terminal:

  1. ./01-discover.sh — fetch the OIDC discovery doc and JWKS.
  2. ./02-login.sh — generate PKCE / state / nonce, open Kenni in the browser.
  3. Sign in. The browser will redirect here, to /callback.
  4. Copy the command shown there and run ./03-exchange.sh '<url>' in your terminal.
  5. ./04-userinfo.sh, ./05-protected-resource.sh, ./06-client-credentials.sh, ./07-refresh.sh — exercise each feature.
  6. ./08-logout.sh — RP-initiated logout (redirects you back here).

If you've just been logged out, that worked.
